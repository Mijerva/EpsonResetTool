# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

Be respectful and keep discussion about the project. Harassment, insults and personal attacks are not accepted.

Report problems privately through the repository's **Security** tab (**Report a vulnerability**) or to the maintainer on GitHub. The maintainer may remove comments and block accounts that break these rules.
